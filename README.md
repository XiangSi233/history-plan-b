# 中国工农红军长征 · 跨学科互动课件（hudong2）

基于你给的模板（`新建文件夹`）做的**图片化 + 三维化**版本：
保留模板的七幕剧情 / 横版地图 / 答题计时 / 地理卡片框架，把里面**原本是 CSS 渐变和手绘 canvas 的部分全部换成真实历史图片和三维场景**，并把文案大幅扩写。

> 三个版本并存，互不影响：
> - `hudong/` 　自由探索版（路线图 + 三维会议现场）
> - `hudong1/` 剧情闯关版（八章 galgame + 跨学科知识卡）
> - **`hudong2/` 本目录**　模板框架 + 全套真实图片 + 重建的三维场景
>
> 本目录还带一条**循环背景音乐**（`assets/audio/bgm.ogg`，Opus 64kbps，1.13 MB），右上角「🔊 音乐」可随时开关。

## 一、怎么跑起来

用了 ES Module 和 `fetch`，**不能用 `file://` 双击打开**，需要一个静态服务器：

```bash
cd hudong2
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000/
```

### 部署

整个目录是**纯静态**，`vendor/three.module.js` 已本地化，**不依赖 CDN、可离线**。拷到服务器根目录即可：

```nginx
server {
    listen 80;
    server_name your.domain;
    root /var/www/hudong2;
    index index.html;
    gzip on;
    gzip_types text/css application/javascript application/json;
    location ~* \.(webp|mp4)$ { expires 30d; }
    location = /index.html { add_header Cache-Control "no-cache"; }
}
```

## 五、三个三维场景

全部用**本地 three.js（r169）+ 程序化生成的几何体和纹理**，没有任何外部 3D 模型。

### 遵义会议室 · `zunyi_meeting`
木质地板、灰泥墙面、三扇夜窗、长桌、桌面摊开的长征地图、纸张、茶碗、油灯（带火焰跳动与光晕）、
六位参会人物 + 四位旁听者（低多边形坐姿，带呼吸动画）、空气中浮尘。
冷暖双光源：窗外月光（冷蓝）+ 油灯（暖橙）。

### 泸定桥 · `luding_bridge`
夜色峡谷：整块崖壁夹峙、湍急河水（流动贴图 + 白沫粒子）、两座石砌桥台、
**13 根铁索**（9 根作桥面、4 根作扶手，按悬链线下垂）、西岸残留木板（其余被抽走）、
对岸大火（双点光源跳动 + 光晕 + 火球）、6 名突击队员沿铁索缓行、雨幕粒子。

### 雪山 · `snow_mountain`
远景仍是**《翻越雪山》油画**，但改成「**只取画里的主峰**」：油画整体下移，画中那排近景士兵被前面的雪坡山脊挡住，
不会再出现「画里的人被切成两半」或者大小比例打架。
前景用 3D 做**一路爬升的雪坡**——地形高度由一个 `H(x, z)` 函数统一生成（越远越高 + 几道山脊起伏），
**人和雪共用同一个 H()，所以行军纵队是踩在雪坡上的**，不会浮在雪面上；再配上露出雪面的岩石（平面着色，给尺度感）、
双层风雪粒子、暖阳（带阴影）+ 冷调补光；两侧改用纯渐变的雪雾幕，转身也不会露出油画的近景人物。
默认机位改成「站在半山腰顺着雪坡往上看」，油画主峰正好落在画面上方。

交互统一：**拖拽旋转 · 滚轮缩放 · 双击复位**，每个场景限制水平旋转范围，避免转到背景背面。

### 三维现场 · 两种模式（自由探索 / 自动模式）

走进任何一个三维现场，先弹出一张**模式选择卡**，两种模式**全程都待在三维会场里**，右上角 `现场模式` 小条随时可以切换、可以「↺ 重来」：

| 模式 | 怎么用 |
|---|---|
| 🎬 **自动模式** | 镜头依次对准发言人（拉近到他胸口），台词在会场上方的对话框里自动播放。适合投屏讲解、老师巡堂。**点对话框或按空格可以跳到下一句** |
| 🖱 **自由探索** | 画面里每个人物头顶都有名牌，鼠标移上去变手型，**点人物（或点名牌）他就开口**；下方对话框列出全场人物的主张与进度 `n / 3`，听完必听的三位自动进入会议结论，也可以点「⏭ 直接进入会议结论」跳过 |

- 走进会场时，**遵义会议**的六位与会者（博古、李德、周恩来、毛泽东、张闻天、王稼祥）都可点，**点名册与剧本 id 一一对应**（`js/story.js` 里 `cast[].id`）。
- 人物名牌是 HTML 元素，每帧按三维坐标投影定位，所以旋转视角时名牌会跟着人走；名牌互相压住时可以在 `scene3d.js` 的 `CAST[].off` 里微调像素偏移。
- 户外现场（泸定桥、雪山）没有可点的人物，选择卡只给「自动模式」，自由探索时进入**自由环视**：自己转视角看现场，点「▶ 听本场讲解」再听这一场的故事。
- 「继续 ▶」按钮在本场讲完后才出现，点了才推进到下一幕的剧情/知识卡。

## 八、怎么改

### 改剧情文案 → `js/story.js`
```js
{ type: 'dialog', bg: 'meeting_room', speaker: '毛泽东', role: '中央政治局委员',
  charLeft: 'mao', text: '……' },
{ type: 'geo', title: '大渡河为什么被称为“天险”？', icon: '🌏',
  images: ['assets/geo/valley.webp'], content: `<h4>地形</h4><p>……</p>` },
{ type: 'quiz', question: '……', options: [{label:'A', text:'……', correct:true}], explanation: '……' },
```
> **点图看大图**：知识卡里的配图、小结页的文物/画作，**点一下就是全屏大图**（`适应屏幕` ⇄ `原图大小` 可切换，原图模式能拖动查看；点空白处 / <kbd>Esc</kbd> / 右上角 ✕ 关闭，双击图片也能切换大小）。
> 知识卡配图规则：**一张图**时自动变成「左图右文」两栏，图吸顶跟随滚动，正文一打开就能看见（不会被大图挤到屏幕外）；**两张图**并排、各限高 150px；不配图就是纯文字。

### 换背景图 → `js/engine.js` 的 `BG_IMAGES`
```js
const BG_IMAGES = { meeting_room: 'assets/photo/zunyi-site-old.webp', /* … */ };
```

### 换人物立绘 → `js/engine.js` 的 `CHAR_IMAGES`
```js
const CHAR_IMAGES = { mao: { img: 'assets/chara/mao.webp', name: '毛泽东' }, /* … */ };
```

### 改地图地点 → `js/map.js` 的 `PLACES`
坐标用**底图像素 ÷ 底图尺寸**，改完就是精确对位：
```js
{ id: 'zunyi', name: '遵义会议', type: 'meeting',
  rx: 348 / 1052, ry: 550 / 757, time: '1935年1月',
  desc: '……', geo: '……', img: 'assets/photo/zunyi-site-old.webp' },
```

### 改三维现场剧本 → `js/story.js` 的 `scene3d` 步
```js
{ type: 'scene3d', sceneName: 'zunyi_meeting',
  label: '遵义会议会址 · 楼上客厅', caption: '一句话说明',
  enterText: '模式选择卡上的背景介绍',
  task: '点击会场中的每个人物，听他们各自的主张',   // 自由探索的提示语
  hint: '（也可以直接点击画面里的人物……）',
  intro:  [ { speaker:'旁白', role:'…', narr:true, text:'…' } ],   // 进入现场先播
  cast:   [ { id:'bogu', name:'博古', role:'…', stance:'按原计划北上',
              lines:[ { speaker:'博古', role:'…', text:'…' } ] } ],  // 可点人物
  require:['bogu','mao','zhou'],                                   // 必听的三位 → 进度 n/3
  climax: [ { speaker:'旁白', narr:true, text:'会议决议……' } ] },  // 本场结论
```
- `cast[].id` 必须和 `js/scene3d.js` 里 `CAST` 的 id 一致，镜头才认得人；
- 没有 `cast` 的户外现场会自动变成「自由环视 + 听本场讲解」；
- 想加人物台词：在对应 `cast[].lines` 里加一条即可，自动模式和自由探索都会播到。

### 换背景音乐 → `assets/audio/bgm.ogg`
整条音乐只放一个文件，循环播放，右上角 HUD 有「🔊 音乐」开关（默认开、音量 32%、切到别的标签页自动暂停、选择记在 localStorage）。
想换成自己的曲子，压到差不多的体积再替换即可：

```bash
# 44.1kHz 立体声 mp3 → Opus 64kbps（约 1.1 MB / 2 分钟，听感基本无损）
ffmpeg -i 你的音乐.mp3 -c:a libopus -b:a 64k -vbr on -application audio -ar 48000 -ac 2 assets/audio/bgm.ogg
```
> 需要兼容 Safari（不支持 Opus）的话，再导一份 `bgm.m4a`（`-c:a aac -b:a 72k`）并在 `index.html` 的 `<audio>` 里补一个 `<source>` 即可。

### 改三维场景 → `js/scene3d.js`
每个场景一个 `buildXxx()` 函数，末尾设置默认机位：
```js
const DESCR = {
  zunyi_meeting: { theta: 0, phi: 1.34, radius: 6.2, target: [0, 1.15, 0], thetaRange: 1.5 },
  // theta/phi/radius：球坐标机位；target：注视点；thetaRange：水平可转范围（弧度）
};
```

## 九、兼容性

- 原生 ES Module，无构建、无后端、无 CDN 依赖
- three.js r169（本地），WebGL + ACESFilmic 色调映射 + PCF 软阴影
- 木纹、灰泥、砖石、雪地、水面、夜空、光晕**全部由 canvas 程序化生成**
- 建议 Chrome / Edge 90+、Firefox 90+、Safari 15+（需 WebGL2 与 WebP）
- 背景音乐用的是 **Opus（.ogg）**：Chrome / Edge / Firefox 都能播；**Safari 不支持时会自动隐藏音乐按钮**，其余功能不受影响（要 Safari 出声就按上一节补一份 `bgm.m4a` 备用源）
- 大屏按 16:9 自适应，浏览器 <kbd>F11</kbd> 全屏即可投屏

**翻页**：**点对话框本身就能翻页**（第一下把字打完，第二下翻下一页），底部不再有「继续」按钮；<kbd>空格</kbd> / <kbd>回车</kbd> / <kbd>→</kbd> 同效，右下角会闪「▼ 点击继续 / 空格」提示。
**自动通读**：按 <kbd>A</kbd>（或点右上角 **▶ 自动**）开启，对话会自己一句句往下播，再按一次关闭；**在三维现场里按 <kbd>A</kbd> 会直接把这一场切成「自动模式」播完**。知识卡 / 答题 / 地图这三步仍然手动过，方便老师控节奏。
**其他键盘操作**：<kbd>Esc</kbd> 关闭弹层（大图 → 知识卡 逐层关），地图可拖拽缩放。
**鼠标操作**：三维现场里拖拽旋转、滚轮缩放、双击复位；自由探索时鼠标移到人物身上会变成手型，点击即发言。
